# Сравнительное исследование удобства (usability) Яндекс.Карт и 2ГИС

**Автор:** Максим Ванчурин | **Дата:** Октябрь 2026

## 🎯 1. Цель и гипотеза
Сравнить удобство использования (usability) двух картографических сервисов на основе экспертной оценки и анализа пользовательских отзывов.
* **Гипотеза:** Яндекс.Карты требуют меньше шагов для построения маршрута, однако 2ГИС предоставляет более полную информацию о заведениях на первом экране.

## 🛠 2. Методология
Исследование проведено в формате экспертной оценки (работа выполнена одним исследователем).
* **Сценарии тестирования:**
  1. Поиск конкретного адреса и построение пешего маршрута.
  2. Поиск ближайшей кофейни с рейтингом > 4.5 и работающей сейчас.
  3. Поиск отзывов и фото конкретного заведения.
* **Метрики:** Количество шагов (кликов/экранов) до цели, время выполнения задачи, эвристическая оценка (10 эвристик Нильсена).
* **Анализ данных:** Парсинг и частотный анализ отзывов из сторов (RuStore/App Store).
